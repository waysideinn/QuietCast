- [ ] 订阅并更新，收藏/未播放/历史重启后保留；RSS 刷新不覆盖旧进度。

- [ ] 真实来电/Siri 中断：只有先前播放、系统允许且内容仍授权时恢复；中断期间手动暂停后不能自动恢复。
