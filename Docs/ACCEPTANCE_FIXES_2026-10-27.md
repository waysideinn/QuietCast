# 听芽验收修复 · 1.1.1（4）

日期：2026-10-27，Asia/Hong_Kong。本次对应用户真机验收提出的五个问题，替代 1.1.0 报告中的搜索地区切换、单集更新和底部容器说明。

## 五项修改

1. **第一次键盘搜索无效**：原搜索提交与文字变化的取消回调存在竞争。改为从原生输入框读取输入法提交后的文字，按 Return 直接提交；后续非空文字变化不会清空刚发出的请求。保留独立“搜索”按钮。快速换词和清空搜索由请求代次保护，晚到请求无法覆盖当前结果。不追加搜索历史。
2. **统一搜索**：移除中国／香港／美国选择，一次查询合并三个公开目录的结果，按 RSS 身份去重，同名但不同 RSS 的节目保留。先完成的结果先显示；部分目录失败保留其他结果并提示，全部失败明确报错。搜索只取目录信息，不批量加载 RSS；播放和订阅前的验证仍保留。榜单来源说明仍如实标注目录地区，当前首页使用中国目录。
3. **底部被播放栏遮挡**：导航内容与底部播放条、标签栏改为纵向实际占位，页面滚动视口在播放条上方结束，并裁剪到视口范围。所有五页及其导航子页共用这一容器。补查合法最大滚动位置，等待滚动静止后检查分类最后一项和“显示更多单集”；修复上一轮仅检查两条底栏相对位置、未检查内容滚动终点的遗漏。
4. **分类加载慢**：优先展示已经加载、通过当前规则校验且分类匹配的 RSS；有效分类缓存直接复用。分类交互使用独立于首页的请求通道，不在首页目录请求后排队。默认最多 8 个候选、RSS 同时最多 4 个，每个成功后立即更新页面，慢源不再拖住全部内容；RSS 使用 6 秒超时、不重试，不为填满展示数量再次启动目录补搜。加载中断的部分缓存会标记为未完成，下次进入继续补齐；旧资料库快照不会替换更新的 RSS。冷启动仍取决于 Apple 目录和各节目 RSS 的网络响应，本轮没有承诺固定秒数。
5. **最近更新**：将“单集更新”改为“最近更新”。每个订阅节目只取最新一集，按发布日期倒序；默认“未播放”在最新一集已完成时隐藏该节目，不用更老的未播放集补位。“全部”仍每个节目最多一集，节目详情继续保留历史单集。
