# 隐私与公开发布说明

## App 运行数据

- 无听芽账号、遥测后台、云同步或付费 AI 接口；App 不向项目服务器上传收听、搜索或家长记录。
- 搜索访问 Apple 公开目录；RSS、封面、音频访问各发布者及托管商。这些第三方可看到正常 HTTP 请求信息，包括网络 IP，不能将“本机保存”解释为完全无网络披露。
- 允许公开 HTTP RSS／音频，优先 HTTPS；HTTP 内容未传输加密。
- 订阅、收藏、进度、下载索引保存在 App 私有资料库；音频在私有 Audio 目录，未开放文件共享。
- 搜索记录保留最近 200 个不同词，拦截记录最多 300 条；只有有效家长授权的页面展示相应记录。
- 家长 PIN 验证材料、失败限制、策略与导入词库使用 Keychain，不将明文 PIN 写入 JSON 或日志。设备系统或备份仍须由用户妥善管理。

## 这次公开快照

公开仓库从当前版本的已跟踪文件建立独立历史，采用项目名与占位邮箱作为提交作者。旧 `.git`、旧作者邮箱与本机网络身份不会推送。保留 App 构建和后续研究所需文件，公开元数据样本中的节目／发布者名称不代表个人使用者资料。

导出时去除已发现的本机用户名、家庭目录、局域网地址、个人签名 Team／签名后 Bundle ID 后缀、描述文件标识；私人真机验收记录改为匿名验证概况。构建目录、IPA、Xcode 用户状态、签名证书／私钥／描述文件、设备资料和 App 沙盒数据不进入仓库。

仓库中测试用 PIN、example 身份、规则中的公开发布账号 ID 属于测试或公开节目数据，不是维护者账户凭据。研究数据并非儿童真实搜索历史。自动扫描只是补充检查，不能替代提交前人工审阅。

公开仓库的 GitHub 拥有者由平台正常显示。若需要连仓库归属都匿名，应使用专门组织或公开项目账号；不能通过修改 commit 作者隐藏拥有者。

## 后续发布流程

1. 只从检查过的源码提交构建，避免将手机资料和证书复制进项目。
2. 运行 `python3 Scripts/audit-public.py .`，检查 `git diff --check` 和待提交列表。
3. 查看实际提交作者与 remote，确保没有把个人信息带入提交消息或 diff。
4. 仅推送经过检查的新历史；不要为了保留旧版本直接推送原私人历史。
5. 如需分享 IPA，单独检查 Release 包与元数据，确保未签名、无个人描述文件／签名资料／用户数据。本次仓库仅分享源码，不附带二进制包。

侧装工具登录和 GitHub 登录均由用户本人完成；授权凭据只由各工具管理，不写进项目。
