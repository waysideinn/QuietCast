# 中文小说音频过滤研究：预注册方案

日期：2026-10-25。共享契约：`9e908672b5ac6afe94a0f6ea4e5d0f31f66b7360`，不修改 App 或 Schema。

## 样本框与采集

Apple Search API 的 CN、TW、US storefront，明确 `media=podcast&entity=podcast&limit=200`，不将 Apple Books 的 audiobook 混入播客目录。中文检索并不保证中文内容；保留 RSS language 和人工语言审核。按小说/正常/边界三组预先列出查询词，查询组只是发现路径，绝不作为真实标签。目标是独立人工标注小说≥300、正常≥300、边界≥150；候选数不能冒充已标注数量。边界是附加维度，真实标签仍为 fiction/nonfiction/uncertain。

Apple 全局串行请求间隔≥3.2秒，缓存、超时、指数退避；不通过并发或多 storefront 绕过限流。RSS 有界下载，不请求 enclosure、音频、图片、登录或付费资源。仅公开 HTTP(S)，阻止本地/私有网络目标及重定向；标明 User-Agent。403/404等不重试绕过；429尊重 Retry-After。每个来源保留请求地址、时间、状态、内容哈希。RSS仅取节目简介及最多8个分布式单集摘要，每段最多600字，保留截断标记，不保存正文/全小说或原始 RSS。节目完整性表示成功解析元数据，不表示收录所有历史单集。

搜索响应只缓存所需元数据，不收集联系邮箱。按 Apple ID 及规范 RSS 合并，保留搜索来源；跨 URL 别名不能臆测为同一个节目。重复作品/网络/作者相关样本可能造成泄漏，应按作品族人工聚类划分开发/测试，至少同 RSS 不跨集。哈希稳定分配70%开发/30%测试；首次锁定测试集之后不调整规则。如确需调整，报告为探索性结果并另收新测试集。

## 标注与测量

先只看元数据标注，不看规则输出。小说全文朗读、长篇虚构演播和短篇小说朗读=fiction；作品讨论、真实事件叙述、文学史、知识课程=nonfiction；混合节目、宣传材料不足、语言不符等=uncertain。每条标签记录人工判读理由、可核对字段、标注者、时间、子类型、边界类型；机器弱标签不得进入正式指标。单集必须独立标注，不自动继承节目标签。

以 block 独算召回（block/全部fiction）及误拦（block/全部nonfiction），precision=fiction block/全部已定性 block，另报 uncertain block 数及 review 比例。缺 RSS 导致的 review 单独列出。节目、单集分别测量，给出分母、混淆矩阵、95% Wilson区间、类别表现及所有错误。样本为检索富集的便利样本，不能宣称全目录准确率或总体精确率。

95%召回和3%误拦仅为探索目标。没有足够独立标签时不发布生产词库、不编造测试准确率。研究候选规则使用 Schema 的 `status=example`，只有完成数据、独立验证、Schema及语义验证才考虑 production。
