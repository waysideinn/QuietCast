# 听芽完整使用手册（1.1.3）

本手册面向安装后实际使用。安装与每周续签见[侧装指南](SIDELOADING.md)。底部五个入口依次为：探索、订阅、收藏、下载、设置；播放开始后，底部会显示迷你播放器。

## 1. 首次设置

1. 签名安装并启动听芽。联网后探索页读取真实公开目录，首次加载可能较慢。
2. 家长进入「设置 → 验证家长 PIN」，设置两次相同的 **6～12 位数字 PIN**，勾选已记录且理解无法找回，再点「设置并进入」。
3. 将 PIN 存入自己的密码管理器。没有云端找回或普通设置重置入口；卸载也不保证清除 Keychain。孩子不应知道家长 PIN。
4. 检查内容过滤、Apple 分类、自定义屏蔽词，并试听准备让孩子接触的节目。测试一条应允许内容与一条应拦截内容。
5. 家长授权两分钟后或 App 离开前台时失效；页面重新要求验证属于正常行为。

App 首次未设置 PIN 时不等于已经完成家长保护配置。内置的是中文小说试用规则，不是覆盖所有不适宜内容的儿童白名单。

## 2. 探索、搜索与添加节目

- 「探索」首页包含节目榜、单集榜、本地推荐、目录发现和分类入口。下拉刷新可重新加载；缓存与来源区别见[发现模块](DISCOVERY.md)。部分推荐是本地计算结果，不是 Apple 编辑推荐。
- 在搜索框输入节目名、作者或主题，点「搜索」或键盘提交。提交后收起键盘，点结果进入节目详情；「取消」或清除按钮回到探索首页。当前首页地区默认 CN，搜索由应用内统一搜索策略处理；本版没有独立的地区选择界面。
- 无结果可能因为目录无收录、网络失败、RSS 获取失败或过滤规则。可换关键词重试；家长可在管理页核对规则和拦截记录。
- 点探索／订阅页右上角「＋」，粘贴公开 RSS 地址或 Apple Podcasts **节目链接**，点「验证并订阅」。验证通过后添加；错误地址、私有权限链接和不支持的 feed 可能失败。
- 当前支持 RSS 2.0，不支持 Atom、付费登录、破解付费内容或批量 OPML。不要把含私人访问令牌的付费 feed 发到公开仓库。

## 3. 节目详情、订阅和单集

进入节目可看作者、简介和单集列表，使用页面的订阅／取消订阅按钮管理节目。订阅后在「订阅 → 全部节目」找回；取消订阅不等于删除每条收听进度。

订阅页的最近更新每个节目最多显示最新一集；若最新一集已听完，「未播放」不会用更早单集补位，可进入节目详情找旧集。可在「未播放／全部」间切换，下拉更新 RSS；列表较长时点「显示更多单集」。右上角时钟进入收听历史。节目详情可查看单集简介；播放按钮直接开始收听，单集更多菜单提供加入队列、下载、收藏、标为已播放／未播放。

过滤后无法显示的内容不会因已订阅、已收藏或已下载自动放行。需要家长明确处理例外。

## 4. 播放器的每项操作

| 操作 | 用法 |
| --- | --- |
| 开始／暂停 | 点单集播放按钮，或迷你／完整播放器的播放暂停按钮 |
| 展开／收起 | 点底部迷你播放器标题或封面展开；点完整播放器左上角向下箭头收起 |
| 拖动进度 | 拖动进度条后松手；总时长尚不可用时不能拖动 |
| 快进／快退 | 点两侧箭头；秒数在「设置 → 播放」分别选择 5、10、15、30、45、60 秒 |
| 指定时间 | 完整播放器右上角「更多播放工具 → 跳到指定时间」，输入秒数、`12:30` 或 `1:02:30` |
| 倍速 | 点「倍速」，选 0.75、1、1.25、1.5、1.75、2、2.5、3 倍 |
| 睡眠定时 | 点「睡眠」，选 5、15、30、45、60 分钟；再次进入可关闭；界面显示剩余时间 |
| 收藏 | 播放器点星标，或单集更多菜单点收藏；在「收藏」页查看，重复操作取消 |
| 查看节目 | 点完整播放器中的节目名／作者入口进入节目详情 |
| 上一集／下一集 | 完整播放器右上角更多菜单操作；可用内容仍受规则限制 |
| 播放队列 | 单集更多菜单「加入队列」；完整播放器列表图标或「编辑队列」进入；编辑时拖动排序或删除 |
| 连续播放 | 在「设置 → 播放」开启／关闭连续播放；队列和后续单集仍需通过过滤 |
| 蓝牙／AirPlay | 点播放器输出按钮选择系统可用设备；连接和可达性由系统处理 |
| 后台与锁屏 | 正常切到主屏或锁屏继续播放，锁屏／控制中心可控制；手动强制退出 App 与正常后台不同 |

进度按单集保存，在暂停、切换、后台等时机以及播放中定期落盘。重新打开可恢复已保存进度，但不代表强制退出、断电或系统杀进程时最后一秒绝不丢失。音频服务器不支持可靠寻址时，跳转可能有偏差。

## 5. 下载、离线与空间管理

1. 单集更多菜单点「下载」，或在完整播放器点下载。
2. 在底部「下载」查看已下载与正在传输的任务。传输中可暂停，暂停后继续，失败后重试；更多菜单可取消任务或删除本地文件。
3. **只有完成并显示在「已下载」的文件才可离线播放**。建议完成后开飞行模式并关闭 Wi-Fi 验证一次。外部封面或尚未缓存的详情可能仍需网络。
4. 「设置 → 下载空间上限」可选 1、3、5、10、20 GB；空间不足时先删除不需要的下载。
5. 下载页「清理已播放完的下载」清理已完成收听的本地音频；当前播放集会受到保护。删除本地音频后，再播可能需要重新联网。
6. 下载内容在 App 私有目录；没有文件共享导出功能，Git 仓库不包含这些音频。iOS 对后台任务调度有自己的限制，强制退出后不可假定会继续下载。

## 6. 家长控制逐项设置

统一入口：「设置 → 验证家长 PIN」。授权过期后重新验证。孩子的普通播放界面不提供规则修改权限。

### 内容过滤与类别

「开启内容过滤」控制总开关；下面按词库提供的类别开关选择过滤范围。当前有效试用内容重点是中文小说／有声书；未提供有效词库的类别不能启用。关闭总开关会显著改变保护范围，请家长主动确认自己的设置。

### Apple 分类

进入「Apple Podcasts 分类 → 查看全部分类与子分类限制」。开关表示该分类是否允许：关闭父分类会隐藏所有子分类；只关闭某个子分类则保留其他子分类。若子分类显示「随父分类隐藏」，需先允许父分类才能独立修改。公开目录分类可能缺失或标错，不能作为唯一判断依据。

### 自定义屏蔽词

在「自定义屏蔽词」输入希望屏蔽的词，点添加或键盘提交；列表中的删除移除该词。先使用精确且有区分度的词，过于宽泛的单字容易误拦截。自定义词依赖元数据匹配，不会检查实际音频内容。

### 允许与禁止例外

「家长例外 → 为已加载节目添加允许／禁止」选择节目，可永久允许／禁止整个节目，也可对已加载的具体单集允许／禁止。现有例外右侧「移除」撤销，节目页也可移除节目例外。

当播放／下载被拦截时，可按提示验证 PIN，查看命中原因，选择「允许此单集」或「允许整个节目」，然后**重新执行原播放或下载操作**。这会建立持久例外，而非只生效一次。严格的优先级见[过滤接口](../schemas/content-filter-interface.md)；修改后以实际判定证据为准，避免相互冲突的例外。

### 规则 JSON 导入

「规则文件 → 从本地 JSON 导入并验证」，在文件选择器选择符合仓库 Schema 的规则。App 会严格校验结构、语义和正则；失败保留原词库。成功后重新校验播放、队列与下载。`rules/fiction-audiobooks.json` 是当前试用规则，`example-*.json` 是接口示例，`rules/research/` 为研究文件，不应直接用作全面防护。

自定义词库导入后会保留；以后覆盖安装新版本不应假定会强制替换家长已选词库。可从规则版本确认实际正在使用的文件。

### 搜索记录

进入「使用记录 → 搜索记录」查看关键词、累计搜索次数和最近时间。记录手动提交的搜索，包括无结果或网络失败；不记录首页推荐和后台分类请求。相同词规范化后合并，最多保留 200 个不同关键词，每词最多 200 字，超限淘汰旧项。从 1.1.2 起开始积累，不补造更早版本的记录。

左滑删除一条；右上角清空并确认删除全部。查看和删除均要求有效家长授权。搜索框不向孩子展示这些历史建议。记录保存在本机，不是远程监控；本地记录不具备防篡改取证保证。

### 拦截记录与误判纠正

进入「被拦截记录」查看节目／单集、入口、日期、分数、规则版本和命中证据。可选择允许该内容或整个节目纠正误判；最多保留 300 条本机记录。记录说明规则如何判断，不证明节目内容一定适合儿童。

### 修改 PIN

在「修改家长 PIN」输入两次相同的新 PIN，保存后同步更新自己的密码管理器。没有忘记 PIN 的在线恢复。PIN、安全策略与导入规则使用 Keychain；普通资料库文件不保存明文 PIN。

1.1.3 的拦截详情会分别显示「当前授权状态」和「当时的拦截原因」。点击「允许这个节目／单集」后显示保存中、成功或具体错误，并滚动到反馈位置；成功后对应按钮显示已允许。单集单独禁止仍优先于节目允许，完成授权后请重新播放或下载。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 安装后提示不信任／不能验证 | 核对签名、开发者信任、网络及证书有效期；见侧装指南 |
| 几天后突然无法启动 | 可能签名过期，用同一身份续签覆盖；不要先卸载 |
| 搜不到／栏目空 | 检查网络，换关键词或下拉刷新，再由家长检查规则；不承诺所有地区都能访问相同目录 |
| 有订阅但没显示某集 | 切换未播放／全部，更新 RSS，检查过滤、节目是否实际发布该集 |
| 下完仍需网络 | 确认文件实际完成且校验可用；音频与封面、目录请求是不同资源 |
| 家长页面自动返回 PIN | 两分钟授权过期或 App 离开前台，重新验证 |
| 提示设备解锁后重试安全存储 | 解锁设备，在设置点重试；不要靠清除偏好设置绕过家长规则 |
| 资料库／搜索记录损坏 | 保留原文件，按页面重试或明确清空搜索记录；不要覆盖唯一的设备备份 |
| 更新后 PIN 或数据异常 | 核对签名账户、Team 与最终 Bundle ID 是否变化；停止卸载操作，先检查原 App 和设备备份 |

手机资料不随 Git 自动备份。删除本地项目之前，应确认远端源码能重新克隆并构建；如果还需要手机数据，也要单独做好自己的加密备份。
